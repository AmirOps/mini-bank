# Mini Bank

## Описание
Это мой первый большой проект по языку програирования - python. Мини банковская ситсема которая работает в терминале

## Возможности
- Создание счёта
- Пополнение баланса
- Снятие средств
- Переводы между счетами
- История операций

## Технологии
- Python

## Запуск

1. Установите Python 3.
2. Склонируйте репозиторий и перейдите в папку проекта.
3. Запустите программу командой:

```bash
python BankSystem.py
```

Если в вашей системе команда `python` не сработает, используйте `python3 BankSystem.py`.
