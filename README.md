# Mini Bank

## Описание
Это мой первый большой проект по языку програирования - python. Мини банковская ситсема которая работает в терминале

## Возможности
- Создание счёта
- Пополнение баланса
- Снятие средств
- Переводы между счетами
- История операций

## Технологии
- Python

## Запуск
Для запуска можно нажать F5 на клавиатуре или на кнопку запустить в правом верхнем углу редактора
