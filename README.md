# Mini Bank

## Описание
Это мой первый большой проект по языку програирования - python. Мини банковская ситсема которая работает в терминале

## Возможности
- Создание счёта
- Пополнение баланса
- Снятие средств
- Переводы между счетами
- История операций

## Технологии
- Python

## Запуск

**Требования:** установленный Python 3.

1. Клонируйте репозиторий:

```bash
git clone https://github.com/AmirOps/mini-bank.git
```

2. Перейдите в папку проекта:

```bash
cd BankSystem
```

3. Запустите программу:

```bash
python BankSystem.py
```

Если команда `python` не работает, попробуйте:

```bash
python3 BankSystem.py
```


Если в вашей системе команда `python` не сработает, используйте `python3 BankSystem.py`.
